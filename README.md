## 🔷 About the Project

This is a **modern, classic, multi-page website** for a traditional Freemasonry Lodge. It is designed to:

- Present the Lodge's mission, services, and process with elegance and authority.
- Showcase Masonic initiation, generational Freemasonry, spiritual protection, and other services.
- Provide a direct, confidential contact channel via **WhatsApp** and **Email**.
- Work entirely **static** — no backend, no server, no database required.
- Be fully **responsive** and beautiful on any device.
- Feature a **Parchment (Light) Mode** toggle for reading comfort.

The **Lodge Agent** is **Doctor Obeah Curandero**, an experienced practitioner and author of esoteric manuals since 2002.

## ✨ Features

### 🎨 Design
- **Modern Classic 2031 aesthetic** — obsidian + antique gold palette
- **Glassmorphic navigation** with scroll-triggered blur
- **Animated hero** with floating gold orbs, sacred grid, and rotating 3-ring sigil
- **Preloader** with sacred diamond spinner
- **Parchment Mode** (light theme) with `localStorage` persistence
- **Micro-interactions** on every hover, focus, and scroll

### 📄 Pages (6 Total)
| Page | File | Purpose |
|------|------|---------|
| Home | `index.html` | Hero, stats, quick preview, CTA |
| About | `about.html` | Lodge history, mission, agent profile |
| Services | `services.html` | 10 services + commitments |
| Process | `process.html` | 5-step timeline |
| Testimonials | `testimonials.html` | Slider with 5 testimonials |
| Contact | `contact.html` | Contact cards + WhatsApp form |

### ⚙️ Functionality
- ✅ **Testimonials slider** — auto-rotate, dots, prev/next, swipe, keyboard arrows
- ✅ **Contact form → WhatsApp** — no backend needed, prefilled message
- ✅ **Animated counters** — IntersectionObserver-triggered
- ✅ **Reveal-on-scroll** — staggered fade-in animations
- ✅ **Floating WhatsApp button** with pulse animation
- ✅ **Back-to-top** button appearing after 600px scroll
- ✅ **Mobile menu drawer** with hamburger toggle
- ✅ **Theme toggle** with OS-preference detection

### 🔍 SEO & Accessibility
- Semantic HTML5 (`header`, `main`, `section`, `footer`, `nav`)
- Meta descriptions and keywords
- Descriptive `aria-label` attributes
- Keyboard-navigable sliders and menus
- Respects `prefers-color-scheme` and `prefers-reduced-motion`
